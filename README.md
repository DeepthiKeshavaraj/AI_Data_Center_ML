# AI Data Center Management using Machine Learning

## Project Overview

This project develops an integrated machine-learning framework for intelligent AI data center management.

Recent research shows that machine learning can be applied to different aspects of data center management, including:

- GPU workload scheduling
- Energy and power management
- Thermal prediction and cooling optimization
- Data center network security

However, these areas are commonly studied independently. The proposed project aims to develop an integrated framework in which predictions from workload, thermal, energy, and security models contribute to a common decision-making process.

The overall framework considers:

Workload → Power → Temperature → Cooling → Resource Availability
